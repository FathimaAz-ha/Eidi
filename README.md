# Eid Wishes Webpage

A mobile-friendly Eid greeting page with elegant typography, personalized wishes, and WhatsApp sharing.

## Features

- Elegant Eid-themed one-page design
- Dua section with highlighted styling
- Dynamic wish line generator
- Personalized share link with sender and message
- WhatsApp share flow
- Copy link button

## Project Files

- `index.html` - main webpage structure
- `styles.css` - design, layout, and responsive styling
- `script.js` - interactions and share logic

## Run Locally

Open `index.html` in your browser.

## Deploy On GitHub Pages

1. Push this repository to GitHub.
2. Go to repository `Settings` -> `Pages`.
3. Under `Build and deployment`, choose `Deploy from a branch`.
4. Select branch `main` and folder `/ (root)`.
5. Save.

Your site will be available at:

`https://fathimaaz-ha.github.io/Eidi/`
